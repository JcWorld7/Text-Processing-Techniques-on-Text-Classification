# Text-Processing-Techniques-on-Text-Classification
Code and data for a study examining how text preprocessing techniques affect classification performance in systematic review.

The Effect of Different Text Processing Techniques on Text Classification
Overview

This repository contains the data and R code used in the study:

“The Effect of Different Text Processing Techniques on Text Classification.”

The goal of this project is to evaluate how different combinations of text preprocessing techniques—tokenization, stopword removal, and stemming—affect the performance of a machine learning classification model in the context of systematic review screening.

A factorial design (4 × 4 × 4) was implemented, resulting in 64 preprocessing conditions.
